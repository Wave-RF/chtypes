# Goldens v1

This directory holds the contract for the v1 goldens, the documents that prove a binding delivers the artifact's own answers faithfully. The artifact producer publishes one signed goldens document per release (one exact ClickHouse version, one build) and attaches it unchanged as an OCI referrer of each platform manifest. `schema.json` is the producer's schema for that document, copied byte for byte and never edited here. `report.schema.json` is the contract for what each binding's runner emits: the runner executes the cases and records what the library returned, and it never compares. The comparator, `scripts/goldens-v1/compare.py`, is normative: it implements the producer's comparison rules (decoded trees, never JSON text) and the report-level rules written down in `docs/guides/goldens-v1.md`, and where a binding disagrees with it the binding is wrong. The synthetic fixtures the comparator's self-test runs on live under `tests/fixtures/goldens-v1/`.
